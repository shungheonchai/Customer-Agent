This local prototype uses fictional customers, books, policies, and transactions. Choosing a customer simulates sign-in.

Enable live LLM replies

An empty LLM_PROVIDER selects scripted fixtures. To use a real model:

  1. Copy .env.example to .env if you do not already have one.
  2. Set these values in your local .env file. Use anthropic, openai, or google for the provider.
LLM_PROVIDER=anthropic
LLM_MODEL=your-model-id
LLM_API_KEY=your-key

Leave LLM_BASE_URL empty for the provider’s public API, or set your compatible gateway URL. Keep keys in your local environment.

Rebuild and restart the web service:

docker compose up --build -d --force-recreate web --wait

Refresh this page and start a fresh conversation. The top-right indicator will show Live and the selected model. For local Python development, restart Uvicorn instead. An invalid or incomplete provider configuration fails explicitly; it does not fall back to scripted replies.
